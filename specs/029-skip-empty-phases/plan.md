# Implementation Plan: Skip Empty Phases

**Branch**: `029-skip-empty-phases` | **Date**: 2026-04-21 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/029-skip-empty-phases/spec.md`

## Summary

Add phase-skipping logic that detects when all players have only "pass priority" as their sole legal action, skips presenting that phase to players, and records the skip in the transcript. The core change is in the turn manager: after `begin_step()` runs but before priority is granted, evaluate whether any player could take a non-pass action. If not, record a skip transcript entry and advance directly to the next step.
