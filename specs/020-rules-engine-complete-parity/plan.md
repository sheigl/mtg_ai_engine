# Implementation Plan: Rules Engine Complete Parity (020)

**Branch**: `020-rules-engine-complete-parity` | **Date**: 2026-04-01 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/020-rules-engine-complete-parity/spec.md`

## Summary

Close all 30 remaining rules engine gaps to achieve complete MTG Comprehensive Rules parity. This feature implements the cleanup step, targeting enforcement (hexproof/shroud/protection), mana ability bypass, split card / MDFC casting, ETB replacement effects, extended trigger pattern recognition, legend rule player choice, correct toughness-0 semantics, blocker damage ordering, additional combat phases, step-granular phase skipping, ward enforcement, kicker resolution effects, damage doublers, phasing, vehicles, morph, adventure cards, mana persistence, split second vs abilities, type-layer overwrites, snow mana, trample to planeswalkers, flanking, fading, echo, P/T switching, foretell, and mutate. All changes are additive extensions to existing engine modules with no new dependencies.

## Implementation Phases

### Phase 1: Data Model Extensions (US1-US30 prerequisites)

**Files**: `mtg_engine/models/game.py`, `mtg_engine/models/actions.py`

Add all new model fields and classes defined in `data-model.md`:
- `DamageModifier` model
- `ManaPoolPersistence` model
- New fields on `Card`, `CastRequest`, `StackObject`, `Permanent`, `ManaPool`, `PlayerState`, `GameState`
- New `LegalAction` action_type values
- New request models: `CrewRequest`, `TurnFaceUpRequest`, `ForetellRequest`

No behavior changes -- data model only. All new fields have defaults, so existing tests pass without modification.

---

### Phase 2: Cleanup Step (US1)

**Files**: `mtg_engine/engine/turn_manager.py`

- Implement `process_cleanup_step(game_state) -> GameState`
- Discard to hand size: set `pending_discard_choice` if hand > max_hand_size
- Remove damage: iterate battlefield, set `damage_marked = 0`
- Expire "until end of turn" effects: reset `power_bonus`, `toughness_bonus`, `crewed_until_end_of_turn`, temporary keyword grants where `*_expires == "end_of_turn"`
- Priority check: call `check_sba()` and `check_triggers()`; if anything fires, grant priority and loop back to a new cleanup
- Wire into turn transition: after end step, call `process_cleanup_step()`

---

### Phase 3: Targeting Enforcement (US2, US20)

**Files**: `mtg_engine/api/routers/game.py`, `mtg_engine/engine/stack.py`, `mtg_engine/engine/combat.py`

- Implement `_validate_targets(game_state, targets, source_card, controller) -> list[str]` (returns list of errors)
- Hexproof check: target has hexproof AND spell controller is opponent -> reject
- Shroud check: target has shroud -> reject
- Protection check: target has protection from quality matching spell -> reject (DEBT: T = targeting)
- Protection SBA for enchant/equip: in `sba.py`, if Aura/Equipment attached to permanent with protection from matching quality -> put to graveyard / unattach
- Wire `_validate_targets()` into `/cast`, `/activate`, `/put_trigger` endpoints

---

### Phase 4: Mana Abilities Bypass Stack (US3, US21)

**Files**: `mtg_engine/engine/mana.py`, `mtg_engine/api/routers/game.py`, `mtg_engine/engine/stack.py`

- Implement `is_mana_ability(oracle_text, is_loyalty=False) -> bool` in `mana.py`
- Implement `resolve_mana_ability(game_state, permanent_id, ability_index) -> GameState` in `mana.py`
- In `/activate` endpoint: check `is_mana_ability()` before calling `stack.activate_ability()`; if True, call `resolve_mana_ability()` directly
- In `_compute_legal_actions()`: tag mana abilities with `action_type="activate_mana_ability"`
- In split second enforcement: allow `activate_mana_ability` action types, block all other activated abilities (US21)

---

### Phase 5: Split Cards, MDFCs, and Aftermath (US4)

**Files**: `mtg_engine/engine/stack.py`, `mtg_engine/engine/zones.py`, `mtg_engine/models/actions.py`

- In `cast_spell()`: when `card.faces` and `len(card.faces) > 1`, read `face_index` from request; populate stack object fields from selected face
- Fuse: when `req.fuse=True`, validate card has fuse keyword, merge both faces' costs and effects
- Aftermath: when `face_index=1` and card layout is `"aftermath"`, validate card is in graveyard; mark for exile on resolution
- MDFC land play: in play-land endpoint, when `card.card_layout == "mdfc"` and `face_index=1`, use back face's type_line/abilities
- Legal actions: emit separate `LegalAction` per castable face, plus fuse action if applicable

---

### Phase 6: Adventure Cards (US18)

**Files**: `mtg_engine/engine/stack.py`, `mtg_engine/engine/zones.py`

- Adventure cast: when `card.card_layout == "adventure"` and `face_index=1`, cast the adventure half; mark `StackObject.is_adventure=True`
- Adventure resolution: if `stack_obj.is_adventure`, exile card to `player.exile` (not graveyard); tag card as adventure-exiled
- Creature cast from exile: when `cast_foretold=False` and card is adventure-exiled, allow casting the creature half (face_index=0) from exile
- Counter handling: if adventure spell is countered, card goes to graveyard (not exile)
- Legal actions: adventure in hand -> two actions; creature in adventure-exile -> one action

---

### Phase 7: ETB Replacement Effects (US5)

**Files**: `mtg_engine/engine/replacement.py`, `mtg_engine/engine/zones.py`

- Implement `apply_etb_replacements(game_state, permanent, controller) -> Permanent` in `replacement.py`
- Scan battlefield for ETB-modifying patterns (enters tapped, counter doubling)
- Call from `put_permanent_onto_battlefield()` before adding permanent to battlefield list
- Handle "enters tapped" effects: override `permanent.tapped = True`
- Handle counter modification: apply multiplier to initial counters

---

### Phase 8: Trigger Pattern Extensions (US6)

**Files**: `mtg_engine/engine/triggers.py`, `mtg_engine/engine/zones.py`

- Implement `check_event_triggers(game_state, event_type, event_data) -> GameState`
- Define event types: `gain_life`, `land_enter`, `creature_dies`, `draw_card`, `sacrifice`, `counter_spell`, `enchantment_enter`, `end_step`
- For each event type, define regex patterns matching common oracle_text trigger conditions
- Wire event calls into: `draw_card()`, `move_permanent_to_zone()`, `gain_life()`, phase transition hooks
- Preserve existing trigger patterns; new patterns are additive

---

### Phase 9: SBA Corrections (US7, US8)

**Files**: `mtg_engine/engine/sba.py`

- **Legend rule (US7)**: Replace auto-keep-newest with `pending_legend_choice` on GameState; player selects which to keep
- **Toughness-0 (US8)**: Create `_put_to_graveyard_sba(permanent, game_state)` separate from `_destroy_permanent()`; toughness-0 creatures go through the non-destruction path (bypasses regeneration and indestructible)

---

### Phase 10: Combat Improvements (US9, US10, US24, US25)

**Files**: `mtg_engine/engine/combat.py`, `mtg_engine/engine/turn_manager.py`

- **Blocker damage order (US9)**: In `assign_combat_damage()`, when an attacker has multiple blockers, assign lethal damage to first in order before next; validate manual assignments comply with this rule
- **Additional combat phases (US10)**: In `turn_manager.py`, after combat-to-postcombat-main transition, check `additional_combat_phases > 0`; if so, decrement and start new combat phase
- **Trample to planeswalkers (US24)**: In trample damage assignment, when attacker is assigned to a planeswalker, excess damage goes to the planeswalker (not the defending player)
- **Flanking (US25)**: In `declare_blockers()` processing, check attacking creatures for flanking keyword; fire -1/-1 trigger against non-flanking blockers

---

### Phase 11: Turn Manager Extensions (US11, US19)

**Files**: `mtg_engine/engine/turn_manager.py`, `mtg_engine/engine/mana.py`

- **Step-granular skipping (US11)**: Before entering each step, check `game_state.step_skip_flags.get(step_name)`. If True, skip the step. Handle one-time skips by clearing the flag after skipping.
- **Mana persistence (US19)**: In the mana-emptying function, check `player.mana_persistence`. For persistent colors, do not empty those colors. For `convert_to_colorless`, convert colored mana to colorless instead of emptying.

---

### Phase 12: Stack Mechanic Extensions (US12, US13)

**Files**: `mtg_engine/engine/stack.py`

- **Ward enforcement (US12)**: When a spell/ability targets a permanent with ward (opponent-controlled source), place a ward trigger on the stack. On ward trigger resolution, set `pending_ward_payment`. On payment submission: if paid, continue; if declined, counter the targeting spell. Parse ward cost from oracle_text.
- **Kicker resolution (US13)**: In `resolve_top()`, when `stack_obj.kicker_paid=True`, parse the kicked effect from oracle_text. Apply the kicked effect instead of or in addition to the base effect. Handle multikicker by checking `stack_obj.kicker_count` (if > 0, apply N times).

---

### Phase 13: Replacement Effects and Layers (US14, US22, US28)

**Files**: `mtg_engine/engine/replacement.py`, `mtg_engine/engine/layers.py`

- **Damage doublers (US14)**: Implement `apply_damage_modifiers(game_state, source, target, amount, is_combat) -> int`. Iterate `game_state.damage_modifiers` in timestamp order, applying multipliers. Call before damage prevention in all damage paths (combat, spell, ability).
- **Type overwrite layers (US22)**: Extend layer 4 in `apply_continuous_effects()` to handle `type_operation="overwrite"`. When overwriting, replace subtypes and set `remove_abilities=True`. In layer 6, process ability removal and grant intrinsic abilities from `grant_abilities`.
- **P/T switching (US28)**: In layer 7d processing, when `switch_pt=True`, swap the creature's effective power and toughness after all other layer 7 modifications.

---

### Phase 14: Permanents with Special Mechanics (US15, US16, US17, US26, US27)

**Files**: `mtg_engine/engine/turn_manager.py`, `mtg_engine/engine/zones.py`, `mtg_engine/api/routers/game.py`, `mtg_engine/engine/sba.py`

- **Phasing (US15)**: In untap step, before untapping: phase in all `phased_out=True` permanents (non-tokens); phase out all `has_phasing=True` permanents and their attachments. Add `get_active_battlefield()` helper; use throughout combat, targeting, SBA, trigger code.
- **Vehicles (US16)**: New `/crew` endpoint. Validate total power >= crew cost. Tap crew creatures. Set `crewed_until_end_of_turn=True`. During cleanup, clear crew status. Add "crew" legal action.
- **Morph (US17)**: New `/turn_face_up` endpoint. Validate face-down, morph cost, controller. Pay cost, set `is_face_down=False`, restore characteristics. Megamorph: add +1/+1 counter. Special action: no stack.
- **Fading (US26)**: In upkeep processing, find permanents with fading. Remove a fade counter; if none, sacrifice.
- **Echo (US27)**: In upkeep processing, find permanents with echo where `echo_paid=False` and `turn_entered_battlefield < current_turn`. Set `pending_echo_payment`. On payment: mark `echo_paid=True`. On decline: sacrifice.

---

### Phase 15: Foretell, Mutate, and Snow Mana (US23, US29, US30)

**Files**: `mtg_engine/api/routers/game.py`, `mtg_engine/engine/stack.py`, `mtg_engine/engine/zones.py`, `mtg_engine/engine/mana.py`

- **Snow mana (US23)**: Add `snow_by_color` tracking to `ManaPool`. When a snow permanent produces mana, flag it. In `can_pay_cost()`, validate `{S}` against snow pool. Decrement both color and snow pools on payment.
- **Foretell (US29)**: New `/foretell` endpoint. Pay {2}, exile card face-down, add to `foretold_cards`. For casting: validate card is foretold, not foretold this turn, pay foretell cost. Add legal actions for both foretell and cast-foretold.
- **Mutate (US30)**: In `cast_spell()`, when `mutate_target_id` is set, validate target is non-Human creature controlled by caster. On resolution, merge cards into mutate pile on target permanent. Fire "whenever this creature mutates" triggers. Handle death: all cards in pile go to graveyard separately.

## Testing Strategy

Each phase has one or more dedicated test files in `tests/test_020/`. Tests follow the existing pattern:
- Build minimal `GameState` from scratch using Pydantic model constructors
- Apply the operation under test by calling engine functions directly
- Assert on resulting state fields

No mocks -- all tests exercise actual engine functions (consistent with `test_018/` and `test_019/` style).

Regression baseline: `python -m pytest tests/ -v` from project root before any changes. Run full suite after each phase. Target: zero failures against existing 447 tests throughout all phases.
