# Implementation Plan: Rules Engine Gap Closure

**Branch**: `019-rules-engine-gap-closure` | **Date**: 2026-03-29 | **Spec**: [spec.md](spec.md)

## Summary

Close 20 identified MTG rules engine gaps relative to Forge parity. The feature extends the trigger system with spell-cast and attack/block event detection, fixes two-step combat damage for first-strike/double-strike, enforces keyword mana cost modifiers (Convoke, Delve, Improvise, Affinity, Emerge), adds death-replacement effects (Persist, Undying), implements stack mechanics (Storm, Buyback, Replicate, Flashback, Escape), adds zone-based mechanics (Cycling, Dredge, Suspend auto-cast), fixes Commander command tax, adds Proliferate and Sagas, and enforces planeswalker rules including Emblems. All changes are additive extensions to the existing engine with no new dependencies.

## Implementation Phases

### Phase 1: Trigger System Extensions (US1, US2)

**Files**: `mtg_engine/engine/triggers.py`

**New functions**:
- `check_cast_triggers(game_state, caster, spell_type_line, spell_name) -> GameState` — called from `cast_spell()` after placing spell on stack; iterates all permanents and emblems looking for "whenever you/a player cast" patterns
- `check_attack_triggers(game_state, attacker_ids) -> GameState` — called from `declare_attackers()` after validation; iterates permanents for "whenever [creature] attacks" patterns; also handles exalted (US18) and battle cry (US18)
- `check_block_triggers(game_state, blocker_ids) -> GameState` — called from `declare_blockers()` after validation

**Pattern constants to add**:
```python
CAST_TRIGGER_PATTERNS = [
    r"whenever you cast (?:an? )?(?P<type>\w+)? ?spell",
    r"whenever a player casts (?:an? )?(?P<type>\w+)? ?spell",
]
ATTACK_TRIGGER_PATTERNS = [
    r"whenever (?:this creature|(?P<type>[a-z ]+) creature) attacks",
    r"whenever (?:a creature|creatures) you control attacks?",
]
BLOCK_TRIGGER_PATTERNS = [
    r"whenever this creature blocks",
    r"when this creature blocks",
]
```

**Integration points**:
- `cast_spell()` in `stack.py` — call `check_cast_triggers()` after `stack.append(stack_obj)`
- `declare_attackers()` in `combat.py` — call `check_attack_triggers()` after validation
- `declare_blockers()` in `combat.py` — call `check_block_triggers()` after validation

### Phase 2: Two-Step Combat Damage (US3)

**Files**: `mtg_engine/engine/combat.py`, `mtg_engine/engine/turn_manager.py`

**Changes to `assign_combat_damage()`**:
```python
def assign_combat_damage(
    game_state: GameState,
    assignments: list[DamageAssignment] | None = None,
    first_strike_only: bool = False,  # NEW
) -> GameState:
```
- When `first_strike_only=True`: only creatures with first strike or double strike deal damage
- When `first_strike_only=False`: only creatures WITHOUT first-strike-only deal damage (double-strikers hit both steps)

**Turn manager step transitions**:
- `FIRST_STRIKE_DAMAGE` step: call `assign_combat_damage(gs, first_strike_only=True)`, run SBAs, grant priority
- `COMBAT_DAMAGE` step: call `assign_combat_damage(gs, first_strike_only=False)`, run SBAs, grant priority
- Transition from `DECLARE_BLOCKERS`: if `has_first_strike_combatants()` → go to `FIRST_STRIKE_DAMAGE`, else skip to `COMBAT_DAMAGE`

### Phase 3: Keyword Mana Cost Modifiers (US4)

**Files**: `mtg_engine/engine/mana.py`, `mtg_engine/models/actions.py`, `mtg_engine/api/routers/game.py`

**New `CastRequest` fields**: `convoke_creature_ids`, `delve_card_ids`, `improvise_artifact_ids`, `emerge_sacrifice_id` (see data-model.md)

**New function in `mana.py`**:
```python
def apply_keyword_cost_reductions(
    base_cost: dict[str, int],
    cast_request: CastRequest,
    game_state: GameState,
    player_name: str,
) -> dict[str, int]:
```
All keywords reduce the generic `{N}` component first. Convoke can also reduce colored components matching the tapped creature's color.

**Affinity**: auto-calculated from battlefield count — no new request field needed.

**Router change**: Call `apply_keyword_cost_reductions()` before `can_pay_cost()` check in the cast endpoint.

### Phase 4: Persist and Undying (US5)

**Files**: `mtg_engine/engine/zones.py`

**Intercept in `move_permanent_to_zone()`** when `to_zone == "graveyard"` and permanent is a creature:
- Check persist: `"persist" in perm.keywords` AND `perm.counters.get("-1/-1", 0) == 0` → return to battlefield with `-1/-1` counter
- Check undying: `"undying" in perm.keywords` AND `perm.counters.get("+1/+1", 0) == 0` → return to battlefield with `+1/+1` counter
- Controller-chooses if both apply (add `PendingChoice` for player selection)

### Phase 5: Storm (US6)

**Files**: `mtg_engine/engine/stack.py`

**In `resolve_top()`**, before applying the spell's effect:
```python
if "storm" in card_keywords:
    storm_count = game_state.spells_cast_this_turn - 1
    for _ in range(storm_count):
        game_state = copy_spell_on_stack(game_state, stack_obj.id)
```

Note: `game_state.spells_cast_this_turn` is already incremented when `cast_spell()` is called (verify this happens, add increment if missing).

### Phase 6: Buyback and Replicate (US7)

**Files**: `mtg_engine/engine/stack.py`, `mtg_engine/models/game.py`, `mtg_engine/models/actions.py`

**Buyback**: Detect via oracle_text regex in `cast_spell()`; add `buyback_paid` to `StackObject`; in `resolve_top()`, if `stack_obj.buyback_paid`, return card to hand instead of graveyard.

**Replicate**: Detect via oracle_text regex; add `replicate_count` to `StackObject`; in `resolve_top()`, call `copy_spell_on_stack()` N times before resolving the original.

---

### Phase 7: Flashback and Escape (US8)

**Files**: `mtg_engine/engine/stack.py`

**Legal action generation**: Scan `player.graveyard` in `_compute_legal_actions()` for flashback/escape patterns; generate `cast_flashback` / `cast_escape` `LegalAction` entries.

**Resolution**: In `resolve_top()`, if `stack_obj.flashback or stack_obj.escape`, exile the card instead of sending to graveyard (append to `player.exile`).

**Graveyard removal**: On cast from graveyard, remove the card from `player.graveyard` (add this to `cast_spell()` when `from_graveyard=True`).

---

### Phase 8: Cycling (US9)

**Files**: `mtg_engine/api/routers/game.py`, `mtg_engine/engine/triggers.py`

**New endpoint**: `POST /game/{game_id}/cycle` — pay cycling cost, discard card, draw card.

**Legal actions**: Add `"cycle"` action type for cards with `Cycling {cost}` in oracle_text.

**Trigger emission**: After cycling, call `check_cycle_triggers(game_state, card_name, type_line)` for "whenever you cycle" patterns.

---

### Phase 9: Dredge (US10)

**Files**: `mtg_engine/api/routers/game.py`, `mtg_engine/engine/stack.py`

**Draw hook**: In `draw_card()`, check if player has dredge-able cards in graveyard. If so, present `LegalAction(action_type="dredge", ...)` before completing the draw.

**New endpoint**: `POST /game/{game_id}/dredge` — choose dredge card or pass to draw normally.

---

### Phase 10: Suspend Auto-Cast (US11)

**Files**: `mtg_engine/engine/turn_manager.py`

**Change**: When suspended card reaches 0 time counters in the upkeep handler, call `cast_spell()` with empty `mana_payment` instead of moving card to hand. Mark the StackObject with `metadata["grant_haste"] = True` if the card is a creature. In `put_permanent_onto_battlefield()`, check for this flag and add `"haste"` to keywords + schedule cleanup at end of turn.

---

### Phase 11: Command Tax (US12)

**Files**: `mtg_engine/api/routers/game.py`, `mtg_engine/engine/mana.py`

**New utility**: `add_generic_to_cost(cost, amount) -> dict[str, int]` in `mana.py`.

**Cast endpoint**: When `req.from_command_zone`, compute `tax = 2 * player.commander_cast_count`, add to effective cost via `add_generic_to_cost()`, validate payment, then increment `commander_cast_count` after successful cast.

---

### Phase 12: Proliferate (US13)

**Files**: `mtg_engine/engine/stack.py`, `mtg_engine/api/routers/game.py`

**Spell effect pattern**: In `_apply_spell_effect()`, detect `r"\bproliferate\b"` → set pending proliferate choice.

**New endpoint**: `POST /game/{game_id}/proliferate` — player submits target list; engine adds one counter of each existing type to each target.

---

### Phase 13: Sagas (US14)

**Files**: `mtg_engine/engine/zones.py`, `mtg_engine/engine/triggers.py`, `mtg_engine/engine/sba.py`

**ETB**: In `put_permanent_onto_battlefield()`, detect Saga type → set `counters["lore"] = 1` → trigger chapter I.

**Upkeep**: In `check_phase_triggers()` (or a new `check_saga_triggers()`), increment lore counter for each saga on upkeep → trigger matching chapter.

**Chapter parsing**: Split oracle_text on roman numeral patterns to extract chapter ability text.

**Sacrifice**: After final chapter triggers and resolves, sacrifice the saga. Implement via delayed trigger or SBA check (`counters["lore"] >= max_chapter AND final_chapter_triggered`).

---

### Phase 14: World Enchantment SBA (US15)

**Files**: `mtg_engine/engine/sba.py`

Add SBA check in `_check_once()`: find all permanents with "world" in type_line; if 2+, keep the newest (by `entered_at` or `entered_turn`), move others to their owners' graveyards.

---

### Phase 15: Unearth SBA (US16)

**Files**: `mtg_engine/engine/sba.py`, `mtg_engine/engine/zones.py`

**SBA**: In `_check_once()`, when `current_step == Step.END`, exile all `perm.unearthed == True` permanents.

**Replacement**: In `move_permanent_to_zone()`, if `perm.unearthed and to_zone != "exile"`, redirect `to_zone = "exile"`.

**Bounce clearing**: When `to_zone == "hand"` for an unearthed permanent (bounced), clear `unearthed = False` on the resulting card (new object).

---

### Phase 16: Planeswalker Rules (US17)

**Files**: `mtg_engine/models/game.py`, `mtg_engine/engine/stack.py`, `mtg_engine/engine/turn_manager.py`, `mtg_engine/engine/replacement.py`

**Loyalty limit**: In `_compute_legal_actions()`, filter out `activate_loyalty` for permanents with `loyalty_activated_this_turn == True`. Reset flag during untap step in `turn_manager.py`.

**Emblem model**: Add `Emblem` class and `GameState.emblems: list[Emblem]`.

**Emblem trigger support**: Iterate `game_state.emblems` in `check_cast_triggers()` / `check_phase_triggers()` / `check_attack_triggers()`.

**Damage redirect**: Add `redirect_to_planeswalker_id: str | None` to damage events; allow routing in `apply_damage_event()`.

---

### Phase 17: Exalted and Battle Cry (US18)

**Files**: `mtg_engine/engine/triggers.py` (within `check_attack_triggers()`)

**Exalted**: If only one attacker, find all permanents with "exalted" keyword owned by that controller; add one pending trigger per exalted instance, each granting +1/+1 to the lone attacker.

**Battle Cry**: For each battle-cry attacker, add a pending trigger granting +1/+0 to all other current attackers.

---

### Phase 18: Partner Commanders (US19)

**Files**: `mtg_engine/api/routers/game.py`, `mtg_engine/models/game.py`

**Validation at game creation**: Allow 2 commanders if both have Partner or matching "Partner with [Name]".

**Model change**: `PlayerState.commander_cast_count: int` → `commander_cast_counts: dict[str, int]` keyed by card name.

---

### Phase 19: Multiplayer "Each Opponent" (US20)

**Files**: `mtg_engine/engine/stack.py`, `mtg_engine/models/actions.py`

**New utility**: `get_opponents(game_state, player_name) -> list[PlayerState]`.

**Spell effect patterns**: Replace single-opponent application with iteration over `get_opponents()` for "each opponent" patterns.

**CastRequest**: Add `opponent_target: str | None` for 3+ player "target opponent" disambiguation.

## Testing Strategy

Each phase has a dedicated test file in `tests/test_019/`. Tests follow the existing pattern:
- Build minimal `GameState` from scratch
- Apply the operation under test
- Assert on resulting state

No mocks — all tests exercise actual engine functions (consistent with `test_018/` style).

Regression baseline: `cd src && python -m pytest tests/ -v` before any changes. Run full suite after each phase.
